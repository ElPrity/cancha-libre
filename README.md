## Cómo abrirlo en tu PC

1. Extraé la carpeta `cancha libre` del archivo ZIP.
2. Abrí la carpeta y hacé doble clic sobre `index.html`.
3. Se abrirá automáticamente en tu navegador (Chrome, Edge, Firefox, etc.).

## Estructura de archivos

- `cancha libre/index.html`: Estructura HTML principal con enlace a Discord y redes.
- `cancha libre/styles.css`: Estilos visuales oscuros/gamer y diseño responsivo.
- `cancha libre/app.js`: Script simple para interacciones de demostración.
- `cancha libre/README.md`: Documentación e instrucciones del proyecto.
